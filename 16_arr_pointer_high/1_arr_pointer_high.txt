1. 배열이란?
    => 같은 타입의 원소들이 연속된 메모리 공간에 배치된 객체입니다.
    => 선언할 떄 [] 해당 키워드로 사용된 변수만 배열이 아닙니다.


2. 인덱스 연산자 기전
    2-1. a[b] -> *(a+b)
    2-2. 이 떄 a는 주소로 변환되고 b는 단순한 숫자가 아니라 배열 요소의 값의 sizeof입니다.
    2-3. int arr [] = {1,2,3};
        => arr[1] -> *(arr+1) -> *(0x... + sizeof(1)) -> *(0x..+4);


3. 포인터 배열
    3-1. char * arr_list [] = { "hello", "world", "apple" };
        => [] > * 
        => arr_list는 배열이고 각 요소는 포인터란 의미입니다.
    3-2. arr_list의 각 요소의 값은 h, w, a의 주소를 가지고 있습니다.
    3-3. hello, world, apple은 읽기 전용 데이터 영역에 존재합니다. -> 수정 불가
    3-4. arr_list[0] -> h의 주소 / &arr_list[0] -> 첫 요소를 가지고 있는 주소, 즉 char ** p;
    2-5. arr_list[1] -> *(arr_list+1) -> *(&arr_list[0] + sizeof(char *)) -> w의 주소를 가리킵니다.


4. 이중 포인터
    4-1. char ** pp = (char *) malloc (sizeof(char *) * 3);
        => malloc을 통해 char *을 값으로 가지고 있는 3개 나란히 붙은 공간을 만들고 그 첫 번쨰 주소를 반환합니다.
        => pp -> 이중 포인터입니다.
    4-2. pp[1], pp[2]는 char *를 값으로 가지고 있는 배열의 요소들입니다.
    4-3. pp[1] = malloc (sizeof(char) * 3); -> malloc으로 값을 char로 갖고 있는 공간을 나란히 만들고 첫 주소를 반환합니다.
    4-4. pp[1]에는 char를 값으로 가지고 있는 첫 주소가 존재합니다.
    4-5. pp[2] -> *(pp+2) -> *(&pp[0] + sizeof(char *)*2) -> pp의 3번쨰 요소의 값을 가리킵니다.


5. 2차원 배열
    5-1. 포인터 배열과 이중 포인터와 큰 차이점은 선언한 크기만큼 원소들의 저장 공간 자체를 통쨰로 확보합니다.
    5-2. ** 2차원은 배열은 배열의 원소가 또 배열인 것을 의미합니다. **
    5-2. char name [3][10];
        => 30개의 char 공간이 실제로 만들어집니다.
        => name[0] -> 10byte / name[1] -> 10byte / name[2] -> 10byte
        => name의 요소들은 배열입니다. 그 요소들도 배열입니다. -> 즉, name[0], name[1], name[2]의 타입은 char [10] 입니다.
        => 다만 name[0], name[1], name[2]는 표현식에서 첫 번째 요소의 주소로 변경됩니다. -> char name [] = "aa"; -> name은 char[], 표현식에서 주소처럼
    5-3. name[1][1] -> *(*(name+1)+1) -> 가장 안쪽의 괄호부터 계산합니다. -> *(name+1) -> 여기서 name은 char [10]를 값으로 가지고 있는 주소입니다.
        -> name + 1은 값의 타입 -> *(name+(sizeof(char) * 10)) -> *(&name[1]) -> 두 번쨰 요소의 값의 첫 번쨰 요소의 주소
        -> *(address + 1) -> address의 값의 타입은 char -> 두 번쨰 요소를 가리킵니다.


6. 포인터 배열이나 이중 포인터도 2차원 배열과 동일한 인덱스 기전을 가지고 있다고 생각
    => pp[1][2] -> pp[1]부터 해석해야함 -> pp[1]에서 1은 char * 크기 만큼
    => char *의 값의 타입은 char -> pp[2]는 char 크기 만큼
