1. 파일이란?
    => 보조기억장치에 저장된 데이터의 단위입니다.

2. 실행 파일 -> 프로그램
    => 보조기억장치에 저장된 실행 가능한 형태

                 파일
                  │
       ┌──────────┼───────────┐
       ↓          ↓           ↓
    문서 파일    이미지      실행 파일
    hello.txt    cat.jpg     program
                              │
                              ↓
                           프로그램

3. C에서 문서 파일을 읽고 쓰려면 OS의 요청해서 처리해야 합니다.
    => 이 때 이 작업을 쉽게 할 수 있도록 표준 입출력 라이브러리를 제공합니다.


4. FILE *fp = fopen("hello.txt", "r");
            보조기억장치
        ┌─────────────────┐
        │   hello.txt     │
        │   실제 데이터   │
        └─────────────────┘
                ↑
                │
              운영체제
                │
                ↓
        ┌─────────────────┐
        │ 열린 파일에 대한    │
        │ 커널의 정보        │
        │ fd_table        │
        │ 파일 위치         │
        │ 접근 권한         │
        │ 상태 정보 등       │
        └─────────────────┘
                ↑
                │
                │ fd = 3
                ↓                
            사용자 공간
        ┌─────────────────┐
        │ FILE 객체        │
        │                  │
        │ buffer           │
        │ fd = 3           │
        │ EOF 상태         │
        │ 오류 상태        │
        │ 기타 stdio 정보  │
        └─────────────────┘
                ↑
                │
                fp
                │
              프로그램
