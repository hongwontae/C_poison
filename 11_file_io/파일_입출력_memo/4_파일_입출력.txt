1. fopen("파일위치/이름.확장자", "mode");
    모드	      의미
    "r"	        읽기
    "w"	        쓰기
    "a"	        이어쓰기
    "r+"	    읽기 + 쓰기
    "w+"	    읽기 + 쓰기, 기존 내용 삭제
    "a+"	    읽기 + 쓰기, 끝에 추가


2. rwa 차이
    2-1. r : 기존 파일을 읽습니다. 파일이 존재하지 않으면 실패합니다.
    2-2. w : 파일이 없으면 생성합니다. 파일이 이미 있다면 기존 내용을 삭제하고 write
    2-3. a : 기존 내용 뒤에 추가하여 write


3. 파일을 여는데 실패 -> NULL을 반환합니다.
    => fopen() 이후에 NULL을 확인해야 합니다.


4. 파일 쓰는 함수
    => fprintf(파일_객체_주소, "write할 문자열"); -> 문자열 작성
    => fputc('char_문자', 파일_객체_주소); -> 문자 작성
    => fputs("문자열", 파일_객체_주소) -> 문자열 작성


5. 파일 읽기 함수
    => fgets(저장할_문자열_주소, size, fp);
    => fgets(buffer, sizeof(buffer), fp);
    => fgetc(fp) -> 하나만 읽습니다.
    => fgets(저장할_문자열_주소, size, fp);
    => fscanf(형식문자열, 저장할 주소) 


6. 파일 입출력 작업이 완료되었다면 fclose(fp)를 사용합니다.
