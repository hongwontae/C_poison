1. FILE *fp;
    => FILE 객체 자료형입니다.
    => *fp -> 그 객체 자료형의 주소입니다.


2. FILE 객체
    => 파일 입출력을 관리하기 위해 사용하는 구조체 형태의 객체입니다.
    => FILE 객체
    ┌──────────────────────────┐
    │ buffer                   │
    │ fd                       │
    │ 현재 위치 정보           │
    │ EOF 상태                 │
    │ 오류 상태                │
    │ buffering 정보           │
    │ 기타 stdio 관리 정보     │
    └──────────────────────────┘

3. fopen()이라는 함수가 FILE 객체를 구성합니다.
    3-1. fd = n;
    3-2. 현재 위치 정보 : 일반적으로 파일의 시작 / 파일을 읽으면 이동합니다. -> FILE 내부 위치 관리와 커널의 열린 파일 위치를 내부적으로 구현함
    3-3. EOF : 파일을 읽다가 끝에 도달하면 TRUE로 변경됨
    3-4. error : 오류 발생 -> 상태 저장 -> ferror(fp) 확인 가능
    3-5. buffer : 내부적으로 구성됨


3. FILE * fp = fopen(..)

    => fopne()을 사용하면 FILE 객체의 주소를 받습니다.
