높은 주소
┌─────────────────────┐
│        Stack        │ ← 지역 변수, 함수 호출 정보
│          ↓          │
│                     │
│                     │
│          ↑          │
│        Heap         │ ← malloc()
├─────────────────────┤
│        .bss         │ ← 초기화하지 않은 전역/정적 변수
├─────────────────────┤
│        .data        │ ← 초기화한 전역/정적 변수
├─────────────────────┤
│        .rodata      │ ← 문자/문자열 리터럴 
├─────────────────────┤
│        .text        │ ← 프로그램의 기계어 코드
└─────────────────────┘
낮은 주소


1. .text
    => 프로그램이 실행할 기계어(명령어)가 들어갑니다.
    => main의 mov, add, return.. 같은 명령어가 .text에 들어갑니다.
    => 읽기 전용입니다.


2. .rodata
    => 문자 리터럴/ 문자열 리터럴이 들어가는 공간입니다.
    => 읽기 전용 공간입니다. / 문자 리터럴이나 문자열 리터럴은 수정할 수 없습니다.


2. .data
    => 초기값이 있는 전역 변수 / 초기값이 있는 static 변수가 들어갑니다.
    => 프로그램 시작부터 정해진 초기값이 필요 -> 실행파일 자체에 초기 데이터가 들어 있습니다.
    => 프로그램 시작부터 특정 초기값을 가지고 있어야 하는 변수를 저장하는 영역입니다.


3. .bss
    => 초기화하지 않은 전역 변수 / 초기화하지 않은 static 변수가 들어갑니다.
    => 초기화하지 않았기에 실행 파일 자체에 데이터가 없고 프로세스가 생성될 떄 마련됩니다.
    => 실행할 때 0으로 초기화해야 하는 공간이 얼마만큼 필요한지 기록해 놓은 영역입니다.


4. heap
    => 동적으로 할당하는 공간입니다.


5. Stack
    => 함수가 호출될 떄 사용하는 영역입니다.
    => 함수 호출이 발생 -> 스택에 쌓임 -> 함수가 끝나면 사라짐
