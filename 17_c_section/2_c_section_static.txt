1. 지역 변수 static
    1-1. 함수 내부의 지역 변수에 static 키워드를 사용하면 함수의 수명이 끝나도 값이 유지됩니다.
        => static 키워드 변수의 초기화는 다시 하지 않습니다. -> 한 번하면 그대로 남음
        void func(void)
        {
            static int count = 0;

            count++;
            printf("%d\n", count);
        } => func()를 여러 번 호출하면 1, 2, 3.... / count = 0으로 초기화하는건 맨 처음 한 번입니다.
    
    1-2. 함수 내부의 지역 변수의 static이라 해서 전역 변수로 변하는게 아닙니다.
        => 스코프는 여전히 func 내부입니다.
    
    1-3. static 지역 변수는 .data or .bss에 저장됩니다.
        => 이 떄 초기값이 존재하는 static 변수는 .data 위치합니다.
        => 초기값이 없는 static 변수는 .bss에 위치합니다.


2. 전역 변수 static
    2-1. 전역 변수 static도 1-3 처럼 위치합니다.

    2-2. static을 사용하지 않은 전역 변수는 다른 파일에서 extern 키워드로 가져와서 사용할 수 있습니다.

    2-3. static을 사용한 전역 변수는 다른 파일에서 extern 키워드를 사용해도 사용할 수 없습니다.
    2-4. 또한 static은 함수에도 붙일 수 있고 다른 파일에서 extern 키워드로 가져와도 사용할 수 없습니다.
